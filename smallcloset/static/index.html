01. 신상마켓 브라우저

계정 정보는 사이트의 실제 로그인 칸에 직접 입력하세요. 세션은 로컬 전용 폴더에 보관합니다. 네트워크 접근·공식 연동 수단·로그인 후 페이지 구조는 아직 확인되지 않았습니다.

화면을 클릭하고 아래 입력 도구를 사용하세요. 화면에서 드래그하면 텍스트를 선택합니다. 수집 중에는 직접 조작을 잠급니다. 주문·결제·메시지 자동화는 제공하지 않습니다.

입력 내용은 전송 직후 비우며 로그·상품·CSV에 저장하지 않습니다. 별도 브라우저 창이 열리는 PC에서는 그 창을 직접 사용할 수 있습니다.

이미지 표는 OCR 선택 후 브라우저 화면에서 표 영역만 드래그하세요. 로그인 화면은 저장하지 않습니다.

02. 수집 범위

사이트에서 남성 분류·검색·거래처 목록으로 직접 이동한 후 실제 상품 링크만 선택하세요. 검색어는 작업 메모로만 저장합니다. URL 경로나 검색 API를 추정하여 호출하지 않습니다.

현재 수집은 실제 페이지를 열어 제목과 링크를 저장하는 검토용 초안입니다. 목록 가격 사전 필터·상세 옵션 자동 추출은 미구현이며, 근거를 입력하기 전에는 통과하지 않습니다. 재수집 시 오래된 수치와 확인 여부는 초기화하고 메모·즐겨찾기는 유지합니다.

판정 원칙

구매 가능한 동일 옵션의 가격과 총장이 모두 확인되어야 통과합니다. 범위 총장은 큰 값, 앞·뒤 총장은 긴 값을 사용합니다. 총장 불명·이미지 행/열 불명·가격 추가금 불명·재고 불명·분리 불가 세트는 확인이 필요합니다.

아우터: 재킷·점퍼·코트·패딩·바람막이 / 상의: 티셔츠·셔츠·맨투맨·후드티·니트 / 바지. 가디건·카디건·후드집업은 상의로 분류합니다. 남성의류 카테고리에서 수집하며, 숏기장·크롭 문구는 총장 미확인 후보로 보관합니다.

외부 유료 API를 사용하지 않습니다. OCR은 로컬 Tesseract로 처리하며 자동 판정 근거로 확정하지 않습니다.
