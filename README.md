# 작은옷장 상품 선별실

남성 의류를 **같은 구매 옵션의 표시 가격·추가금·총장·재고**로 판정하는 로컬 프로그램입니다. Python/FastAPI, SQLite, Playwright/Chromium, 한국어 Tesseract OCR을 사용합니다. 외부 유료 API, 주문·결제·거래처 메시지 기능은 없습니다.

**현재 상태: 실행 가능한 선별·근거 검토 프로그램입니다. 신상마켓 자동 수집 완성본은 아닙니다.** 클라우드의 실제 접속 시 프록시 `403 CONNECT`와 Chromium 인증서 오류가 확인되어, 로그인 방식·실제 상품 HTML/옵션 구조·공식 API 유무를 확인하지 못했습니다. 실제 상품 20개 수집 및 실제 이미지 사이즈표 검증은 **0개 / 미실행**입니다. 자동으로 가격·옵션을 추출한다고 가장하지 않으며, 초기 DB에 샘플 상품을 넣지 않습니다.

## 설치와 실행

### Windows 10/11 · 64비트

**WSL이나 리눅스, 별도 Python·Tesseract 설치가 필요 없습니다.**

1. [최신 프로그램 ZIP](https://github.com/ikm021212-hash/jo/archive/refs/heads/smallcloset-app.zip)을 다운로드하고 **모두 압축 풀기**를 선택합니다. ZIP 안에서 배치 파일만 실행하지 마세요.
2. 풀린 폴더의 **`START-WINDOWS.bat`를 더블클릭**합니다.
3. 처음에는 전용 Python, 프로그램, Chromium, 한국어·영어 OCR을 자동 설치합니다. 인터넷 연결이 필요하고 몇 분 걸릴 수 있습니다. 설치 후 브라우저에 프로그램 화면이 자동으로 열립니다.
4. 프로그램의 **수집 · 로그인 → 일반 Chrome에서 가져오기** 안내에 따라 확장프로그램을 한 번 설치합니다. 평소 Chrome의 로그인 상태를 사용합니다.

자동 설치, OCR, 47개 테스트와 화면·CSV·데스크톱 실행은 [실제 Windows CI에서 통과](https://github.com/ikm021212-hash/jo/actions/runs/40199892340)했습니다. 실제 신상마켓 로그인·상품 자동 추출 검증과는 구분합니다.

설치·복구만 따로 실행하려면 `INSTALL-WINDOWS.bat`를 더블클릭합니다. 실행 중인 검은 창은 켜 두고, 종료할 때는 그 창에서 `Ctrl+C`를 누릅니다. 브라우저 화면만 닫으면 프로그램은 계속 실행됩니다. 시작 파일을 다시 누르면 이미 실행 중인 프로그램 화면을 엽니다.

데이터·세션·프로그램 전용 Python과 OCR은 `%LOCALAPPDATA%\SmallCloset`에 보관합니다. 새 ZIP을 다른 폴더에 풀어도 상품과 메모는 유지합니다. 업데이트 전에는 기존 프로그램 창을 종료하세요. 시스템 Python이나 PATH, Windows 전역 실행 정책을 변경하지 않고 관리자 권한 없이 사용자 폴더에 설치합니다. 배치 파일의 실행 정책 옵션은 해당 PowerShell 프로세스에만 적용하며 TLS·파일 해시 검증은 유지합니다.

이 설치 경로는 Windows 10/11 **x64**용입니다. Windows ARM64·32비트는 아직 지원하지 않습니다. 회사 PC의 실행 제한이나 네트워크 차단이 있으면 빨간 오류 메시지를 확인해 주세요. 설치 창은 오류가 나도 닫히지 않게 안내합니다.

### Linux / macOS

Python 3.12+, curl, Tesseract 5가 필요합니다. 현재 로컬 회귀 검증 환경은 Linux/Python 3.12/Chromium 154입니다. Windows 설치/실행 검증 상태는 [VALIDATION.md](VALIDATION.md)에 별도로 기록합니다.

Tesseract가 없는 PC에서 먼저 설치합니다.

```bash
# Ubuntu / Debian
sudo apt-get install tesseract-ocr
# macOS에서는 대신: brew install tesseract
```

저장소 디렉터리에서 실행합니다.

```bash
bash scripts/install.sh
bash scripts/run.sh
```

`install.sh`는 가상환경, 고정된 직접 Python 의존성, Chromium(시스템에 없을 때), 한국어·영어 OCR 모델을 준비하고 테스트합니다. OCR 모델은 공식 Tesseract 저장소에서 TLS로 받아 고정 SHA256을 검증합니다. 한국어는 `tessdata_best` 모델을 사용합니다. 시스템에 Chromium 실행에 필요한 공유 라이브러리가 없다면 Playwright 안내에 따라 `.venv/bin/python -m playwright install-deps chromium`을 실행해야 합니다. 이 명령은 OS 패키지 관리자 권한이 필요할 수 있습니다.

`run.sh`가 표시한 루프백 주소를 **실행 중인 PC의 브라우저**에서 열면 됩니다. 기본 포트는 8000입니다. 클라우드 온보딩 화면에는 localhost 미리보기 기능이 없습니다. 현재 클라우드의 주소를 사용자 PC에서 열 수 있다고 보장하지 않습니다. 사용자가 직접 로그인하려면 이 코드를 PC에서 실행하는 방법이 가장 간단합니다.

현재 클라우드에서는 다음 경로로 실제 설치·실행을 확인했습니다.

```bash
cd /workspace/jo
SM_DATA_DIR=/workspace/.smallcloset-data bash scripts/install.sh
SM_DATA_DIR=/workspace/.smallcloset-data bash scripts/run.sh
```

## 일반 Chrome에서 로그인과 수집 시작

자동화 Chromium의 사람 확인이 반복되고 평소 Chrome에서는 통과한다면 **일반 Chrome 연동**을 사용합니다. 보안 확인을 자동으로 풀거나 우회하지 않습니다. 정상 Chrome에서 직접 통과·로그인한 뒤 열린 상품을 사용자 클릭으로 가져오는 방식입니다.

1. 기존 작은옷장 실행 창에서 Ctrl+C로 종료하고 새 ZIP을 모두 푼 뒤 `START-WINDOWS.bat`를 실행합니다. 기존 데이터와 메모는 AppData에 유지됩니다.
2. 프로그램의 **수집 · 로그인 → 일반 Chrome에서 가져오기**에서 확장프로그램 폴더 경로를 복사합니다. **폴더 열기 · Windows**도 사용할 수 있습니다.
3. 평소 Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켠 뒤 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다. 앞에서 복사한 `chrome-extension` 폴더를 선택합니다. Chrome이 조직 정책으로 확장 설치를 막으면 관리자의 허용이 필요하며 프로그램이 그 정책을 변경하지 않습니다.
4. 같은 일반 Chrome에서 신상마켓에 직접 로그인합니다. 이미 로그인돼 있으면 그대로 사용합니다. 로그인 상태는 Chrome에 남으며 프로그램은 비밀번호·쿠키·인증 헤더를 읽거나 전송하지 않습니다. 계정 정보가 코드에 포함되지 않으며 ID/비밀번호 자동 입력은 구현·검증하지 않았습니다.
5. **남성의류 카테고리**에서 상품을 직접 골라 **제품설명** 탭을 엽니다. Chrome 확장 아이콘에서 **작은옷장 · 현재 상품 가져오기**를 선택하고, 남성 카테고리에서 이동한 상품인지 체크한 뒤 **현재 상품 가져오기**를 누릅니다. 현재 열린 상품 1개씩 가져옵니다. 이 방식은 자동 페이지 순회를 하지 않습니다.
6. 분류를 고릅니다. **가디건·카디건·후드집업·후드 집업은 상의로 분류**합니다. 총장 수치가 없어도 **숏기장·크롭** 표현이 있으면 버리지 않고 확인 필요 후보로 보관합니다. 표현만으로 실제 길이를 추정하거나 통과시키지 않습니다. 하의는 팬츠·청바지·슬랙스·조거팬츠·카고팬츠·반바지 등 바지류 전체를 포함합니다. 하의 기준은 29,300원/100cm이며 상한을 포함합니다. 상품명과 선택한 설명, 또는 화면에서 발견한 키워드 주변 문구를 근거로 보존합니다. 화면 문구에는 추천 상품이 섞일 수 있으므로 해당 상품의 설명인지 확인해야 합니다.
7. 작은옷장 화면의 상품에서 **근거·메모 편집**을 열어 정확한 상품명·거래처·동일 옵션 가격·추가금·총장·재고와 원문 근거를 확인합니다. HTML 표의 기장/총장 수치도 검토 후보이며 자동 확정하지 않습니다. 이미지 사이즈표는 표만 잘라 상품 편집의 로컬 OCR에 올리고 원본을 대조합니다.

프로그램의 포트가 기본 8000과 다르면 수집 화면에 표시된 포트를 Chrome 확장프로그램에 입력합니다. 확장프로그램 설치 후 처음에는 사이트 읽기와 로컬 프로그램 접근을 Chrome이 확인할 수 있습니다. 확장프로그램의 사이트 읽기 범위는 신상마켓 두 도메인, 전송 대상은 PC의 루프백 주소뿐입니다. 키·세션을 복사하지 않으며 원격 디버깅으로 기존 Chrome 프로필에 접속하지 않습니다.

별도 자동화 브라우저는 수집 화면의 **고급** 안에 남아 있습니다. 그 방식의 목록 수집 기본 한도는 20, 순차 요청 간격은 2초이며 남성의류 카테고리 확인이 필요합니다. 보안 확인·로그인 만료·접근 제한이면 멈추고 결과와 작업 큐를 보존합니다. 사람 확인이 반복되면 그 자동화 창의 수집을 재시도하지 말고 일반 Chrome의 수동 가져오기를 사용합니다.

## 기본 선별 기준

| 분류 | 가격 상한 | 총장 상한 |
|---|---:|---:|
| 아우터 | 51,500원 | 70cm |
| 상의 | 23,800원 | 68cm |
| 바지 | 29,300원 | 100cm |

상한을 포함하며 **선별 기준**에서 바꿀 수 있습니다. 기존 상품도 즉시 다시 판정합니다. 재킷·점퍼·코트·패딩·바람막이는 아우터, 티셔츠·셔츠·맨투맨·후드티·니트는 상의로 분류할 수 있습니다. 가디건·카디건·후드집업은 사용자 지정 규칙에 따라 상의입니다. 다른 애매한 품목은 실제 사이트 분류를 확인하고 상품 편집에서 변경합니다. 사이트 분류 자동 매핑은 아직 없습니다.

- 같은 옵션의 가격과 총장이 모두 기준 이내이고 재고가 확인되면 **조건 충족**입니다. S 67/M 69인 상의는 S만 통과합니다.
- 다른 옵션의 최저 가격과 최단 총장을 합치지 않습니다. 색상별 가격·재고가 다르면 옵션 행을 나눕니다.
- 범위 `67~69cm`는 69cm, `앞 65 / 뒤 68`은 68cm로 판정하며 원문을 보존합니다. `67/69`처럼 의미가 불분명하면 확인 필요입니다.
- 가슴·허리단면·인심·밑위 등을 총장으로 해석하지 않습니다. `약`, `±`, 인치, 불명확한 혼합 수치도 자동 확정하지 않습니다.
- 총장·가격·추가금·재고·사이즈·남성 여부·근거 확인이 빠지면 통과시키지 않습니다. 확인된 가격 또는 총장이 이미 초과하면 해당 옵션은 미충족입니다. 실패 옵션 외에 미확인 옵션이 남아 있으면 상품은 확인 필요입니다.
- 개별 가격/총장을 구분할 수 없는 세트는 확인 필요입니다. 배송비·부가세는 별도 표기 필드에 기록하고 가격 계산에 임의로 가감하지 않습니다.

## 결과·저장·내보내기

세 판정별 탭, 대표 이미지(실패 시 원문 링크), 옵션별 원문·가격·추가금·색상·재고·판정 이유, 수집 시각, 가격/총장 근거를 표시합니다. 가격순·총장순 정렬, 분류·거래처·즐겨찾기 필터, 제외, 메모를 지원합니다. URL의 추적 매개변수·프래그먼트를 제거하고 정규화해 중복을 갱신합니다. 사이트 상품 ID 형식이나 도메인 간 별칭은 미확인이라 이를 기반으로 한 병합은 하지 않습니다.

상품을 체크하면 선택 상품을, 체크하지 않으면 현재 필터 결과를 CSV로 내보냅니다. CSV는 UTF-8 BOM으로 저장하여 Excel에서 한글을 읽을 수 있습니다. 상품 링크·거래처·가격·사이즈별 총장·충족 옵션·메모·근거 등을 포함하며 수식 주입 문자를 처리합니다. 브라우저 프로필이나 인증 헤더는 내보내지 않습니다.

데이터 기본 경로는 Windows에서 `%LOCALAPPDATA%\SmallCloset`, Linux/macOS에서 `~/.local/share/smallcloset`입니다. `SM_DATA_DIR`로 변경할 수 있습니다.

```text
products.sqlite3     상품, 메모, 기준, 작업 큐
evidence/            사용자가 선택/업로드한 사이즈표 PNG
browser-session/     로컬 전용 로그인 프로필 — Git·로그·결과 공유 금지
tessdata/            검증된 로컬 OCR 모델
browsers/            필요한 경우 Playwright Chromium
windows-env/         윈도우 전용 Python 가상환경
python/              자동 설치한 전용 Python
tools/               SHA256으로 검증한 uv 실행 파일
```

데이터는 저장소 밖에 둡니다. `data/`, `.smallcloset-data/`, `.env`, 가상환경은 Git에서 제외합니다. Unix에서는 디렉터리를 소유자 전용으로 설정하고 Windows에서는 사용자 AppData 폴더의 기본 접근 권한을 사용합니다. 세션 삭제는 프로그램을 종료한 뒤 `browser-session/`만 삭제하면 됩니다. 전체 폴더를 결과 파일로 공유하지 마세요. 프로그램은 루프백에만 바인딩하며 외부 공개를 지원하지 않습니다.

환경 변수: `SM_DATA_DIR`(데이터 경로), `SM_CHROMIUM`(브라우저 실행 파일), `SM_HEADLESS=1`(창 없이 앱 안의 실제 브라우저 사용), `SM_PORT`(포트), `SM_TESSDATA`(직접 실행 시 OCR 모델 경로). 실행 파일은 모델·브라우저 경로를 자동 설정합니다. 현재 환경의 HTTPS 프록시 설정은 브라우저에서도 사용하며 TLS 검증은 유지합니다. Windows에서는 DLL을 포함한 공식 `tesserocr` wheel을 사용하고, OCR은 별도 프로세스에서 UTF-8로 처리하며 45초 제한을 적용합니다.

## 검증과 남은 작업

자세한 실행 결과는 [VALIDATION.md](VALIDATION.md)를 보세요.

```bash
SM_TESSDATA="${SM_DATA_DIR:-$HOME/.local/share/smallcloset}/tessdata" SM_BROWSER_TESTS=1 .venv/bin/python scripts/test.py
.venv/bin/python scripts/smoke_ui.py
.venv/bin/python scripts/smoke_desktop.py
```

Windows 개발자 검증은 PowerShell에서 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 -Mode Test`로 실행합니다. 이 모드는 검증용 의존성을 추가로 설치하며 임시 DB에서 테스트합니다.

테스트는 임시 DB와 **테스트 전용 상품/HTML/이미지**를 사용합니다. 실제 DB에 가짜 상품을 넣지 않습니다. 브라우저 테스트는 실제 Chromium에서 가로/세로 HTML 표·제품설명 탭·로그인 필요·CAPTCHA 일시정지를 검증하지만, 신상마켓의 실페이지 검증을 대체하지 않습니다.

아직 구현하지 않은 부분: 실제 사이트 전용 목록 가격 사전 필터, 상품명/거래처/상가/가격/옵션/재고의 자동 추출, 카테고리/검색 자동 탐색, 여러 페이지/무한 스크롤 자동 순회, 이미지 표의 자동 옵션 연결. 현재는 근거를 확인해 입력해야 합니다. 공개 연동 API나 자동화 허용 범위도 미확인입니다.

접속 가능 환경이 준비되면 실제 로그인 후 20개 범위에서 목록·제품설명·옵션·이미지 구조를 확인하고, 그 근거로 자동 추출기를 추가해야 합니다. 실제 사이즈별 총장 차이 상품과 이미지 표 상품도 그때 검증해야 합니다. 현재 초안에 저장한 네트워크 도메인은 `sinsangmarket.kr`, `www.sinsangmarket.kr`이며, 저장은 현재 런타임 반영이나 게시를 의미하지 않습니다. 사이트가 실제 사용하는 다른 인증/CDN 도메인은 관측 후 추가 검토가 필요합니다.
