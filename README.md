# 작은옷장 · 남성 상품 자동 수집

일반 Chrome에서 남성 상품 목록을 열고 **한 번 시작하면 기본 20개를 순서대로 방문·저장**하는 로컬 프로그램입니다. 상품마다 가져오기 버튼을 누르지 않습니다. 실제로 존재하는 상품 링크와 제품설명·디테일컷을 확인하며 상품명·사진·사이즈표·옵션 근거를 수집합니다.

**자동 수집 기능은 구현했지만, 실제 신상마켓에 로그인한 상품 20개 검증은 아직 0개입니다.** 현재 환경의 사이트 접속 제한 때문에 실사이트의 목록/옵션 구조와 공식 연동 API를 직접 확인하지 못했습니다. 존재하지 않는 사이트 API나 전용 CSS를 추측하지 않고 실제 페이지에 있는 표준 DOM·Product/Offer 구조화 데이터를 읽습니다. 그 자료가 없거나 대응이 모호하면 자동 통과시키지 않습니다. Windows에서 시험 페이지 20개를 자동 처리한 검증과 실사이트 검증은 구분합니다.

## Windows에서 시작

Windows 10/11 x64용입니다. WSL·리눅스·별도 Python·Tesseract 설치가 필요 없습니다.

1. [최신 ZIP](https://github.com/ikm021212-hash/jo/archive/refs/heads/smallcloset-app.zip)을 **모두 압축 풀기** 합니다.
2. 풀린 폴더의 **START-WINDOWS.bat**를 더블클릭합니다. 처음에는 전용 Python·OCR·브라우저를 설치하므로 인터넷 연결이 필요하고 몇 분 걸릴 수 있습니다.
3. 프로그램의 **수집 · 로그인 → 일반 Chrome에서 자동 수집**에서 확장프로그램 폴더 경로를 복사합니다.
4. 평소 Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축해제된 확장 프로그램 로드**를 누릅니다. 새 ZIP의 **chrome-extension** 폴더를 선택합니다.
5. 평소 Chrome에서 신상마켓에 직접 로그인하고 **남성 상품 목록**을 엽니다. 검색 범위를 지정하려면 사이트의 실제 검색 기능으로 원하는 목록을 먼저 여세요.
6. 확장 아이콘의 **작은옷장 · 남성 상품 자동 수집**에서 분류·한도(기본 20)를 정하고 남성 카테고리 확인 체크 후 **현재 목록 자동 수집 시작**을 누릅니다.

그 뒤에는 상품을 하나씩 열거나 버튼을 누를 필요가 없습니다. 팝업을 닫아도 진행합니다. 수집이 사용하는 Chrome 탭은 작업이 끝날 때까지 다른 용도로 이동하지 마세요. 프로그램에서 결과·진행률·실패 수를 확인하거나 확장을 다시 열어 확인할 수 있습니다.

업데이트 시 기존 실행 창에서 **Ctrl+C**로 종료하고 새 ZIP을 풀어 실행합니다. 기존 수동 가져오기 확장(0.3 버전)이 설치되어 있다면 Chrome 확장 목록에서 기존 작은옷장 확장을 제거한 뒤 새 폴더를 로드하세요. 상품 DB와 메모는 AppData에 유지되며 일반 Chrome의 사이트 로그인 상태도 그대로입니다.

설치 복구는 **INSTALL-WINDOWS.bat**를 실행합니다. 실행 중 검은 창은 켜 두고 종료할 때 Ctrl+C를 누릅니다. 기본 포트 8000을 다른 프로그램이 사용하면 화면에 표시된 실제 포트를 확장에도 입력합니다. Windows ARM64·32비트는 지원하지 않습니다.

## 자동 수집 방식

- 현재 목록의 이미지·표시 가격·실제 HTTPS 링크가 함께 확인된 카드에서 상품 URL을 읽습니다. 중복 URL과 추적 매개변수를 정리합니다. 목록에서 링크를 확인하지 못하면 이유를 표시하고 멈춥니다.
- 목록을 제한된 횟수 스크롤하고, 실제 `rel=next` 링크가 있을 때만 제한된 추가 페이지를 확인합니다. 한도보다 적은 링크만 확인되면 확인된 개수만 처리합니다. 사이트 전체를 무제한 수집하지 않습니다.
- 목록에 **최저 가격**이 명시되고 단일 금액으로 확인된 경우에만 상한 초과 상품을 상세 방문 전에 제외합니다. 여러 금액이나 불명확한 가격을 임의로 선택하지 않습니다.
- 상품 상세를 순차 방문하며 상품 사이에 2초 이상 기다립니다. 오류는 제한적으로 1회 재시도하고, 보안 확인·로그인 만료·접근 제한이면 재시도하지 않고 일시정지합니다.
- 페이지에 실제로 존재하는 유일한 **제품설명·디테일컷(보기)** 요소만 엽니다. 실제 링크가 있으면 해당 상세 보기로 이동합니다. 임의의 내부 API·상품 ID 경로는 만들지 않습니다.
- 상품명은 명시적인 Product 데이터, 상품명 의미 속성, 단일 제목 또는 실제 목록 제목을 근거로 읽습니다. 일반 페이지 제목만 확인되면 상품명 확인이 필요하다고 기록합니다. 판매자 이름은 명시된 seller 데이터가 있을 때만 사용합니다.
- 확인한 대표 이미지는 가능한 경우 PNG로 로컬 저장합니다. 이미지 재로딩에 로그인 쿠키나 원격 핫링크가 필요하지 않게 합니다. 저장할 수 없으면 원문 링크로 확인하게 합니다.
- 상세/디테일컷의 이미지 사이즈표 후보를 로컬 Tesseract로 읽고 원본 PNG·OCR 텍스트를 보관합니다. 이미지 접근이 불가능하거나 판독/행·열 대응이 불명확하면 확인 필요입니다. 유료 외부 API는 사용하지 않습니다.

## 판정 기준

| 분류 | 가격 상한 | 총장 상한 |
|---|---:|---:|
| 아우터 | 51,500원 | 70cm |
| 상의 | 23,800원 | 68cm |
| 하의 · 바지 | 29,300원 | 100cm |

상한을 포함하며 화면에서 수정할 수 있습니다. 기존 결과도 현재 기준으로 다시 판정합니다.

- **가디건·카디건·후드집업·후드 집업은 상의**입니다.
- **팬츠·청바지·슬랙스·조거팬츠·카고팬츠·반바지 등 바지류 전체**를 하의로 포함합니다.
- 총장 수치가 없어도 **숏기장·크롭** 문구가 있으면 후보로 저장합니다. 실제 총장을 추정해 통과시키지 않고 확인 필요로 표시합니다.
- 같은 옵션의 가격·총장·재고를 함께 확인해야 통과합니다. S 67/M 69인 상의는 S만 통과할 수 있습니다. 서로 다른 옵션의 최저 가격과 최단 총장을 합치지 않습니다.
- 자동 가격/재고 판독은 실제 페이지에 명시된 **사이즈별 Product/Offer**와 표시 가격이 대응할 때 사용합니다. 최종 옵션 가격을 사용하며 임의 추가금을 만들지 않습니다. 배송비·부가세는 임의 가감하지 않습니다.
- 총장은 실제 HTML 표에서 사이즈 행·총장/기장 열·cm 단위가 명확하고 서로 충돌하지 않을 때 자동 확인합니다. 인심·밑위·가슴단면 등을 총장으로 쓰지 않습니다. 범위는 상한, 앞/뒤 원문은 긴 값으로 판정합니다.
- OCR 텍스트는 자동 확정하지 않습니다. 이미지 원본과 대응을 검토해야 합니다. 명시적 사이즈·가격·재고 자료가 없는 페이지도 확인 필요로 저장하고 없는 값을 만들지 않습니다.
- 세트의 개별 가격/총장을 구분할 수 없으면 상품 편집에서 해당 항목을 체크해 확인 필요로 보관합니다.

원문의 키워드 주변 문구에는 추천 상품이 섞일 수 있으므로 해당 상품 설명인지 근거를 대조할 수 있습니다. 미확인 필드는 **근거·메모 편집**에서 확인 후 갱신할 수 있습니다. 이 검토 기능은 수집 시작/진행에 필수인 상품별 조작이 아닙니다.

## 중지·재개·저장

확장의 **일시정지/재개** 또는 프로그램의 **자동 수집 일시정지**를 사용합니다. 작업 번호·대기 URL·완료 결과는 로컬 SQLite에 저장합니다. 보안 확인/로그인 화면에서 재개를 눌러도 그 확인을 직접 끝내기 전에는 진행하지 않습니다. 완료된 상품을 다시 수집하면 최근 데이터로 갱신하며 메모·즐겨찾기·제외 상태는 유지합니다. 확인하지 못한 최신 가격을 이전 가격으로 대체해 통과시키지 않습니다.

일반 Chrome의 쿠키·비밀번호·인증 헤더를 읽거나 복제하지 않습니다. 기존 로그인 상태를 사용하는 방식이며 ID/비밀번호 자동 입력은 구현하지 않았습니다. 보안 확인을 자동 해결하거나 브라우저 신호를 숨기지 않습니다. 확장 읽기 권한은 신상마켓 두 도메인과 로컬 프로그램 주소로 제한합니다. 조직 정책이 확장 설치를 막으면 그 정책을 변경하지 않습니다.

결과는 조건 충족/확인 필요/조건 미충족으로 구분하며 정렬·분류/거래처 필터·즐겨찾기·제외·메모를 지원합니다. 선택한 상품 또는 현재 필터 결과를 **UTF-8 BOM CSV**로 내보냅니다. 원문 상품 URL·거래처·가격·사이즈별 총장·충족 옵션·메모·근거를 포함하며 로그인 세션은 포함하지 않습니다. 주문·결제·거래처 메시지 기능은 없습니다.

## 데이터 위치

Windows: `%LOCALAPPDATA%\SmallCloset` / Linux·macOS: `~/.local/share/smallcloset`. `SM_DATA_DIR`로 바꿀 수 있습니다.

```text
products.sqlite3  상품·메모·기준·작업 큐
evidence/         로컬 대표 사진·사이즈표 PNG
tessdata/         체크섬 검증한 한국어/영어 OCR 모델
windows-env/      전용 Python 가상환경
python/, tools/   전용 Python·검증한 uv 실행 파일
browsers/         개발 검증/고급 경로용 Chromium
browser-session/  고급 별도 브라우저를 사용했을 때만 생기는 로컬 프로필
```

일반 Chrome 로그인은 Chrome 자체 프로필에 남습니다. 사용자 데이터는 Git 대상에서 분리하며 전체 프로필 폴더를 결과로 공유하지 않습니다. 실행 프로그램은 루프백에만 바인딩합니다.

## Linux/macOS 및 개발 검증

Python 3.12+, Tesseract 5가 필요합니다. Linux는 `sudo apt-get install tesseract-ocr`, macOS는 `brew install tesseract`로 준비할 수 있습니다.

```bash
bash scripts/install.sh
bash scripts/run.sh
```

Windows 개발자 검증은 PowerShell에서 다음을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 -Mode Test
```

[Windows 검증 결과](https://github.com/ikm021212-hash/jo/actions/runs/40208852806): **72개 테스트와 자동 20개 시험 수집, 디테일컷 총장, OCR, 이름·거래처·이미지 저장/화면 로딩, 보안 중지·재개 통과**. 시험용 HTML/이미지/임시 DB를 사용하며 실제 계정이나 상품 데이터는 넣지 않습니다. 상세 이력과 실사이트 미검증 항목은 [VALIDATION.md](VALIDATION.md)에 구분했습니다.

실사이트가 표준 상품 링크·명시적 옵션/사이즈 자료를 제공하지 않는 경우에는 사이트 전용 구조 확인과 추가 어댑터 작업이 필요합니다. 현재 이 환경에서는 실제 신상마켓 로그인을 완료하지 못했으므로 실제 상품 20개 검증, 비공개 구조 대응, 공식 API 유무는 아직 확인하지 못했습니다.
