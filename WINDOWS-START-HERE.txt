작은옷장 자동 수집 0.4 · Windows x64

1. 기존 프로그램이 실행 중이면 검은 창에서 Ctrl+C로 종료하세요.
2. 새 ZIP을 '모두 압축 풀기' 한 뒤 START-WINDOWS.bat를 더블클릭하세요.
3. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드를 켜세요.
   기존 수동 가져오기 확장을 제거하고 새 ZIP의 chrome-extension 폴더를 불러오세요.
   폴더 경로는 프로그램의 '수집 · 로그인' 화면에서 복사할 수 있습니다.
4. 평소 Chrome에서 신상마켓에 로그인하고 남성 상품 목록을 여세요.
5. Chrome 확장 아이콘의 '작은옷장 · 남성 상품 자동 수집'을 여세요.
   분류·한도(기본 20개)를 정하고 남성 카테고리 확인 체크 후
   '현재 목록 자동 수집 시작'을 한 번 누르세요.

그 뒤에는 상품마다 버튼을 누를 필요가 없습니다.
프로그램이 사용하는 Chrome 탭은 다른 용도로 이동하지 마세요.
상품명·이미지·옵션·표를 읽고 제품설명·디테일컷도 확인합니다.
확장 팝업을 닫아도 진행합니다. 프로그램에서 결과를 확인하세요.

중지는 확장의 일시정지 또는 프로그램의 자동 수집 일시정지를 사용하세요.
보안 확인이나 로그인 만료가 나오면 직접 처리한 뒤 확장에서 재개하세요.
완료한 결과와 대기 상품은 로컬에 유지됩니다.

가디건·후드집업은 상의, 팬츠·청바지 등 바지류 전체는 하의입니다.
숏기장·크롭 문구가 있어도 실제 총장이 없으면 확인 필요로 보관합니다.
기준: 아우터 51,500원/70cm, 상의 23,800원/68cm, 하의 29,300원/100cm 이하.
원문이 불명확한 가격·총장·옵션을 임의로 채워 통과시키지 않습니다.

프로그램 사용 중 검은 창은 켜 두세요. 종료는 Ctrl+C입니다.
리눅스·WSL·별도 Python 설치가 필요하지 않습니다.
기존 Chrome의 로그인 상태를 사용하며 비밀번호 자동 입력은 없습니다.

Windows에서 시험 데이터 20개 자동 수집과 화면 로딩 검증은 통과했습니다.
실제 신상마켓 상품 20개 검증은 아직 하지 못했습니다.
사이트가 필요한 링크·명시적 정보를 제공하지 않으면 멈추거나 확인 필요로 기록합니다.
