작은옷장 윈도우 실행 방법

1. 다운로드한 ZIP 파일을 오른쪽 클릭하고 '모두 압축 풀기'를 선택하세요.
2. 풀린 폴더에서 START-WINDOWS.bat를 더블클릭하세요.
3. 처음에는 필요한 프로그램을 자동으로 내려받습니다. 인터넷 연결이 필요하고 몇 분 걸릴 수 있습니다.
4. 설치가 끝나면 인터넷 브라우저에 작은옷장 화면이 열립니다.
5. '수집 · 로그인' → '일반 Chrome에서 가져오기'의 안내를 따르세요.
   Chrome의 chrome://extensions에서 개발자 모드를 켜고 chrome-extension 폴더를 불러옵니다.
6. 평소 Chrome에서 로그인한 뒤 남성의류 카테고리의 상품을 직접 열고 확장 버튼으로 가져오세요.
   보안 확인이 반복되는 자동화 브라우저 창은 사용하지 마세요.

리눅스, WSL, 별도 Python·OCR 설치는 필요 없습니다.
Windows 10/11 64비트(x64)용이며 ARM64·32비트는 아직 지원하지 않습니다.

프로그램을 쓰는 동안 검은 실행 창은 닫지 마세요.
종료하려면 검은 창에서 Ctrl+C를 누르세요.
설치가 잘못되었으면 INSTALL-WINDOWS.bat를 실행하여 다시 설치할 수 있습니다.
오류가 나오면 그 오류 문구를 알려주세요.

상품과 메모, 로그인 세션은 사용자 PC의 %LOCALAPPDATA%\SmallCloset에 저장됩니다.
새 버전을 다른 폴더에 풀어도 상품 기록은 유지됩니다. 업데이트 전에는 실행 중인 프로그램을 종료하세요.
로그인 세션 폴더를 공유하거나 GitHub에 올리지 마세요.

현재는 가격·총장·옵션의 근거를 직접 확인하는 선별 프로그램입니다.
신상마켓에서 실제 상품을 자동 추출하는 기능은 아직 완성되지 않았고 실제 20개 상품 검증도 하지 못했습니다.
자세한 기능과 남은 작업은 README.md, 검증 결과는 VALIDATION.md를 확인하세요.

가디건·후드집업은 상의입니다. 총장 미표기라도 숏기장·크롭 문구가 있으면 확인 필요 후보로 저장합니다.
일반 Chrome의 기존 로그인 상태를 사용하며 계정·비밀번호 자동 입력은 포함되지 않습니다.
